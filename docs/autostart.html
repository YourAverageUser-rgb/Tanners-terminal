Quick path · Browser kiosk on startup

If you just want to fly: a one-line shortcut that opens Chrome or Edge fullscreen on this dashboard at every sign-in.

1 · Create the shortcut

Press Win + R, paste this, and press Enter:

shell:startup
Opens the Windows Startup folder.

2 · Drop a startup .bat in that folder

Right-click → New → Text Document, name it xbox.bat, then paste one of these:

Microsoft Edge (recommended):

start msedge --kiosk "https://youraverageuser-rgb.github.io/Tanners-terminal/xbox.html" --edge-kiosk-type=fullscreen

Google Chrome:

start chrome --kiosk "https://youraverageuser-rgb.github.io/Tanners-terminal/xbox.html"

3 · Test it

Sign out and back in. Windows should jump straight to the Xbox dashboard, fullscreen. Press Alt+F4 or Win+D to escape kiosk mode if needed.

Best path · Native app with Electron

For real Xbox-like polish (no browser chrome, real autostart in Windows, controller passthrough, file system access for scanning installed games), wrap it as an Electron app.

1 · Scaffold

npm init -y
npm install --save-dev electron
npm install --save electron-store auto-launch

2 · main.js

const { app, BrowserWindow } = require('electron');
const path = require('path');
const AutoLaunch = require('auto-launch');

const xboxLauncher = new AutoLaunch({ name: 'Xbox PC' });
xboxLauncher.enable().catch(() => {});

function createWindow() {
    const win = new BrowserWindow({
        width: 1600,
        height: 900,
        fullscreen: true,
        frame: false,
        backgroundColor: '#0a0d12',
        webPreferences: {
            preload: path.join(__dirname, 'preload.js'),
            contextIsolation: true,
            nodeIntegration: false
        }
    });
    win.loadFile('docs/xbox.html');
    win.setMenuBarVisibility(false);
}

app.whenReady().then(createWindow);
app.on('window-all-closed', () => { if (process.platform !== 'darwin') app.quit(); });

3 · package.json scripts

"main": "main.js",
"scripts": {
    "start": "electron .",
    "build": "electron-builder"
}

4 · Real game scanning (preload.js)

This is what makes the auto-scan actually find your installed Xbox app games. Expose a renderer-safe API that scans the standard install paths:

// preload.js
const { contextBridge, ipcRenderer } = require('electron');
const fs = require('fs');
const path = require('path');

const XBOX_PATHS = [
    'C:\\\\XboxGames',                  // Xbox app default on Windows
    'C:\\\\Program Files\\\\WindowsApps' // UWP / Game Pass
];

contextBridge.exposeInMainWorld('XboxNative', {
    scanInstalled: () => {
        const games = [];
        for (const root of XBOX_PATHS) {
            try {
                if (!fs.existsSync(root)) continue;
                for (const entry of fs.readdirSync(root)) {
                    const full = path.join(root, entry);
                    try {
                        const stat = fs.statSync(full);
                        if (stat.isDirectory()) games.push({
                            id: entry,
                            title: entry.replace(/_.+$/, '').replace(/\\./g,' '),
                            path: full,
                            sizeBytes: dirSize(full)
                        });
                    } catch(e) {}
                }
            } catch(e) {}
        }
        return games;
    }
});

function dirSize(p) {
    try {
        let s = 0;
        for (const f of fs.readdirSync(p)) {
            const fp = path.join(p, f);
            const st = fs.statSync(fp);
            s += st.isDirectory() ? dirSize(fp) : st.size;
        }
        return s;
    } catch(e) { return 0; }
}

Then in xbox.js, if window.XboxNative exists, call XboxNative.scanInstalled() in runScan() and merge the results into the library. The web build falls back to the mock data.

5 · Build the installer

npx electron-builder --win nsis

The installer registers Xbox PC in Windows Startup so the next reboot opens straight into the dashboard. Add app.setLoginItemSettings({ openAtLogin: true }) to be doubly sure.

Launching real games from the dashboard

Xbox app installs put games inside C:\XboxGames\<Title>\Content with a MicrosoftGame.config file. To launch, spawn the executable from main.js:

const { spawn } = require('child_process');
ipcMain.handle('launch-game', (_, exePath) => {
    spawn(exePath, [], { detached: true, stdio: 'ignore' }).unref();
});

Game Pass / UWP titles need the shell:appsFolder trick:

explorer.exe shell:appsFolder\Microsoft.624F8B84B80_8wekyb3d8bbwe!Game

Party / messaging real integration

The web build simulates parties and messages locally. To wire to actual Xbox Live presence and friends, you need to OAuth against Microsoft and call the Xbox Live REST API.

  • Auth: Microsoft identity platform → XSTS token → XUID
  • Friends list: GET https://peoplehub.xboxlive.com/users/me/people
  • Presence: GET https://userpresence.xboxlive.com/users/xuid({xuid})/presence
  • Messages: POST https://xblmessaging.xboxlive.com/network/...

Xbox doesn't publish a free public party-voice API — but for a fan launcher you can route party voice through Discord with the Discord Rich Presence + Voice SDK and overlay it inside this UI.

Controller setup

This dashboard reads the standard Gamepad API, so any Xbox controller plugged in over USB or paired over Bluetooth works out of the box. The buttons map exactly the same as a Series X|S console:

  • A = select / play
  • B = back
  • X = context menu
  • Y = quick info
  • Xbox button = open guide
  • View / Menu = captures / options
  • LB / RB = switch tab

Open Settings → Controller in the dashboard to test rumble.

What if I want it to literally replace the Windows shell?

Advanced — at your own risk. You can swap explorer.exe for the Xbox PC executable so Windows boots into the dashboard with no taskbar / desktop. Edit:

HKEY_CURRENT_USER\Software\Microsoft\Windows NT\CurrentVersion\Winlogon\Shell

Set Shell to the full path of Xbox PC.exe. Reboot. To revert, sign in via Ctrl+Alt+Del → Task Manager → Run new task → explorer.exe and change the value back. This is a one-way trip if you don't know what you're doing — only do this on a machine you can reinstall.
